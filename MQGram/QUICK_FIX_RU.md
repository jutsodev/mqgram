# Быстрое решение: Функции MQGram не работают

## Проблема
Вы включили функции в настройках MQGram, но они не работают.

## Решение (3 шага)

### Шаг 1: Обновите код
Я уже исправил код. Теперь настройки сохраняются немедленно.

**Что изменилось:**
- Файл `MQGram/MQGramSettingsUI/Sources/MQGramSettings.swift`
- Добавлен вызов `synchronize()` для немедленного сохранения

### Шаг 2: Пересоберите приложение
```bash
# Если используете Bazel
python3 build-system/Make/Make.py build \
    --configurationPath=build-system/appstore-configuration.json \
    --codesigningInformationPath=build-system/fake-codesigning \
    --configuration=release_arm64

# Или через GitHub Actions
# Просто сделайте commit и push - сборка запустится автоматически
```

### Шаг 3: После установки
1. **Откройте настройки MQGram:**
   - Настройки → Ваш профиль
   - **Долгое нажатие** на строку "Telegram Stars"
   - Откроется вкладка MQGram

2. **Включите нужные функции:**
   - Например: "Анти-удаление", "Режим призрака", etc.

3. **ВАЖНО: Полностью перезапустите приложение:**
   - Закройте приложение (свайп вверх в переключателе приложений)
   - Запустите заново

4. **Проверьте, что настройки сохранились:**
   - Снова откройте настройки MQGram
   - Убедитесь, что переключатели остались включенными

## Проверка работы функций

### Anti-Revoke (Анти-удаление)
1. Включите "Анти-удаление"
2. Попросите кого-то отправить вам сообщение и удалить его
3. Вы должны увидеть сообщение с пометкой "удалено"

### Ghost Mode (Режим призрака)
1. Включите "Режим призрака" или конкретную подфункцию
2. Прочитайте сообщения в чате
3. Собеседник не должен видеть "прочитано"

### Anti-Self-Destruct (Анти-самоуничтожение)
1. Включите "Анти-самоуничтожение"
2. Попросите отправить вам "view once" фото
3. Фото должно остаться после просмотра

## Если всё ещё не работает

```
Настройки MQGram → Проверьте, что переключатели включены
```

### Проверьте версию
```
Убедитесь, что установлена версия с исправлением
```
